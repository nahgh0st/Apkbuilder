# 🚀 APK Builder\n\nA web-based APK builder powered by GitHub Actions. Upload your Google AI Studio app ZIP files and build APKs automatically using GitHub's infrastructure.\n\n## ✨ Features\n\n✅ **Web Interface** - Clean, modern UI hosted on GitHub Pages  \n✅ **GitHub Actions Powered** - Automatic builds using GitHub's servers  \n✅ **Drag & Drop Upload** - Easy file uploads  \n✅ **Build Types** - Support for Debug and Release APKs  \n✅ **Email Notifications** - Get notified when builds complete  \n✅ **APK Artifacts** - Download built APKs from GitHub Actions  \n✅ **No Server Required** - Fully GitHub-hosted solution  \n\n## 🚀 Quick Start\n\n### 1. Access the Web UI\n\nVisit: **https://nahgh0st.github.io/Apkbuilder**\n\n### 2. Create a GitHub Personal Access Token\n\n1. Go to [GitHub Settings → Developer settings → Personal access tokens](https://github.com/settings/tokens)\n2. Click \"Generate new token (classic)\"\n3. Give it a name (e.g., \"APK Builder\")\n4. Select scopes:\n   - ✅ `repo` (full control of private repositories)\n   - ✅ `workflow` (update GitHub Action workflows)\n5. Click \"Generate token\"\n6. **Copy the token** - you'll need it for the web UI\n\n### 3. Configure GitHub Secrets\n\n1. Go to your repository **Settings → Secrets and variables → Actions**\n2. Click \"New repository secret\"\n3. Add two secrets:\n   - **Name:** `EMAIL_USER` | **Value:** your-email@gmail.com\n   - **Name:** `EMAIL_PASSWORD` | **Value:** your-app-password\n\n### 4. Enable GitHub Pages\n\n1. Go to your repository **Settings → Pages**\n2. Set source to \"Deploy from a branch\"\n3. Select `main` branch and `/ (root)` folder\n4. Your site will be live at `https://nahgh0st.github.io/Apkbuilder`\n\n### 5. Build Your APK\n\n1. Open the web UI\n2. Upload your Google AI Studio app ZIP file\n3. Select build type (Debug or Release)\n4. Enter your email\n5. Paste your GitHub Personal Access Token\n6. Click \"Trigger Build\"\n7. Check GitHub Actions for build progress\n8. Download your APK from the artifacts\n\n## 📋 How It Works\n\n```\nUser Upload → GitHub Pages UI → Upload to Repo → Trigger Workflow\n                                                          ↓\n                                    GitHub Actions Build Process\n                                    ├─ Checkout code\n                                    ├─ Download uploaded ZIP\n                                    ├─ Setup JDK 17 & Gradle\n                                    ├─ Build APK\n                                    ├─ Upload artifact\n                                    ├─ Send email notification\n                                    └─ Cleanup\n                                                          ↓\n                                    User Downloads APK from Artifacts\n```\n\n## 📧 Email Configuration (Optional)\n\nTo receive email notifications when builds complete:\n\n### For Gmail:\n\n1. Enable 2-Factor Authentication on your Gmail account\n2. Go to [Google App Passwords](https://myaccount.google.com/apppasswords)\n3. Select \"Mail\" and \"Windows Computer\" (or your device)\n4. Generate an app password\n5. Copy the 16-character password\n6. Add it to GitHub Secrets as `EMAIL_PASSWORD`\n7. Set `EMAIL_USER` to your Gmail address\n\n### For Other Email Providers:\n\nEdit `.github/workflows/build-apk-web.yml` and modify the email step to use your provider's SMTP settings.\n\n## 📁 File Structure\n\n```\n.\n├── index.html                          # Web UI (GitHub Pages)\n├── .github/workflows/build-apk-web.yml # Build workflow\n├── build-apk.yml                       # Original APK build workflow\n├── README.md                           # This file\n└── uploads/                            # Temporary uploaded files\n```\n\n## 🔄 Workflow Details\n\n### `.github/workflows/build-apk-web.yml`\n\nThis workflow:\n- Accepts input from the web UI (upload path, build type, email)\n- Downloads the uploaded ZIP file\n- Extracts and prepares the Android project\n- Sets up JDK 17 and Gradle\n- Builds the APK (Debug or Release)\n- Uploads the APK as a GitHub Actions artifact\n- Sends an email notification\n- Cleans up temporary files\n\n## 🔐 Security Notes\n\n⚠️ **Important:**\n- Your GitHub token is used **only in your browser** to upload files and trigger workflows\n- Never commit or share your personal access token\n- The token is not stored anywhere\n- GitHub Secrets are encrypted and not exposed\n- Use app-specific passwords for email accounts\n\n## 🐛 Troubleshooting\n\n### Build fails with \"gradle: command not found\"\n\n- The workflow uses the correct JDK and Gradle versions\n- Ensure your Android project has a `build.gradle` file\n- Check the workflow logs for detailed error messages\n\n### APK not found after build\n\n- Check the workflow logs in GitHub Actions\n- Ensure your project structure matches expected Gradle layout\n- Verify the `app/build.gradle` file exists\n\n### Email notifications not received\n\n- Verify `EMAIL_USER` and `EMAIL_PASSWORD` secrets are set\n- For Gmail, ensure you generated an App Password (not your account password)\n- Check Gmail's \"Less secure app access\" is enabled if needed\n- Check spam/trash folders\n\n### Token authentication fails\n\n- Verify the token has `repo` and `workflow` scopes\n- Ensure the token hasn't expired\n- Re-generate a new token if needed\n\n## 📚 Resources\n\n- [GitHub Personal Access Tokens](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/creating-a-personal-access-token)\n- [GitHub Actions
